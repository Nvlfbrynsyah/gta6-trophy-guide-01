# GTA VI Trophy Guide

[![make.fun](https://make.fun/badge/gta6-trophy-guide-01.svg)](https://make.fun/competitions/gta6-trophy-guide-01) [![rank](https://make.fun/badge/gta6-trophy-guide-01/noval-febriansyah/gta6-trophy-guide-01/rank.svg)](https://make.fun/competitions/gta6-trophy-guide-01) [![reward](https://make.fun/badge/gta6-trophy-guide-01/noval-febriansyah/gta6-trophy-guide-01/reward.svg)](https://make.fun/competitions/gta6-trophy-guide-01)

An offline-first GTA VI trophy tracker for all 55 trophies. Follow the four-stage Leonida roadmap, filter by story, missable, collectibles, or activities, and open any trophy for an original route note and its source links. Progress stays in the browser, with JSON export and import for a portable checklist. Story spoilers can be hidden until a trophy is marked earned. Save at each chapter start and visit Lucia’s Chapter 1 balcony for Positive Mental Attitude before advancing; mission replay is unavailable.

## Run it

From this directory:

```sh
node serve.ts
```

Then open [http://localhost:8080](http://localhost:8080).

The app is static and offline-ready: the browser loads its HTML, CSS, module, and trophy JSON from `app/`.
